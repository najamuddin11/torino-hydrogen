TORINO LEATHER — DESIGN 6 / CHARACTER IN MOTION

Open index.html after extracting the entire ZIP. Keep all accompanying files and assets together, or serve the folder using a static web server.

This is a separate headless design concept for a future Shopify Hydrogen storefront. Earlier designs are unchanged. See research-and-build.md for verified storefront references, animation details, and the Hydrogen integration plan.

SCROLL EXPERIENCE
Photo aperture expansion, scroll-linked text illumination, rotating product photography with three detail chapters, a horizontal collection gallery controlled by vertical scrolling, and parallax artisan photography.
Mobile uses shorter scenes and a swipeable collection gallery. Motion off and reduced-motion preferences restore a normal reading layout.

FILES
Working presentation preview plus React scene components and the shared motion controller in hydrogen-components/. The React files require integration into a Hydrogen app; this ZIP is not a complete connected Hydrogen application or a Shopify theme install package.

SOURCE AND LIMITATIONS
Original Torino photos, colors, products and all 402 captured source routes are retained. Source captured September 30, 2026. Editorial headlines are proposed creative copy. Search, collections, product selections, content pages and a device-local sample bag work in the preview.
No live checkout, inventory, payments, accounts, gift card issuance or contact submissions are connected. Shopify configuration and live Storefront API integration are required before launch.
